# Per-image test predictions

Twelve factorial runs plus EfficientNet-B0 wrote one CSV per checkpoint (636 test images each).
The files live on Google Drive:

https://drive.google.com/drive/folders/1D1omtnkRBEjLJYE2qvVIfMUGWt8Dsp67

Do not put `best.pt` weights in this GitHub repository. PeerJ needs the prediction CSVs and the summary tables already in this folder, not the 377 MB zip of checkpoints.
